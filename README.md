# 📊 Интерактивное приложение для решения математических и финансовых задач

**Финансы · Производные · Статистика — в одном приложении**

Образовательное веб-приложение, разработанное на языке R с использованием фреймворка Shiny.

## 🎯 Цель проекта

Создание интерактивного инструмента для автоматизации математических и финансовых вычислений, позволяющего пользователям получать результаты расчётов и изучать их графическое представление.

## 🧮 Функциональные возможности

### 💰 Финансовые расчёты

Расчёт сложных процентов и будущей стоимости вложений, вычисление аннуитетного платежа по кредиту и определение чистой приведённой стоимости инвестиционного проекта (NPV).

### 📐 Производные

Вычисление производных математических функций, определение значения производной в заданной точке, построение графика функции и касательной к ней.

### 📊 Статистика

Обработка числовых данных, вычисление среднего арифметического, медианы, дисперсии и стандартного отклонения. Визуализация распределения с помощью статистических графиков.

## 🛠️ Используемые технологии

**R** — язык программирования для выполнения вычислений.

**RStudio** — среда разработки и запуска приложения.

**Shiny** — библиотека для создания интерактивного веб-интерфейса.

**HTML/CSS** — оформление пользовательского интерфейса.

**Base R Graphics** — построение графиков.

## 🚀 Как запустить приложение

Для работы необходимо установить R и RStudio.

Установить библиотеку:

`install.packages("shiny")`

Открыть проект в RStudio, выбрать файл `app.R` и нажать **Run App**.

## 🎓 Практическая значимость

Приложение может использоваться студентами при изучении математического анализа, статистики и финансовой математики. Оно помогает автоматизировать расчёты и наглядно представить полученные результаты.

## 📌 Перспективы развития

В дальнейшем проект может быть дополнен новыми математическими задачами, расширенной визуализацией и возможностью экспорта результатов.
